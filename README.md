📌 Overview

The News Aggregator Platform is a MERN stack-based web application that curates and displays news articles from multiple leading news websites using RSS feeds. Initially built to focus on tech news, the platform is designed to be easily scalable for broader categories. The system automatically fetches, processes, and updates news in real-time, providing users with a seamless reading experience.

🚀 Features

📰 Aggregated News Feeds – Collects and displays articles from multiple sources in a structured format.

🔄 Real-time Updates – Automatically fetches the latest news to keep users informed.

📂 Category-based Filtering – Allows users to browse news by category (initially focused on tech but scalable).

🏎 Fast and Responsive UI – Built with React for a smooth user experience.

📡 Scalable Backend – Uses Node.js and Express to handle data efficiently.

📊 MongoDB Database – Stores and organizes news articles for quick access.
